# 🌸 UI Adventures

UI Adventures é um portfólio pessoal criado para reunir e apresentar projetos de desenvolvimento web, principalmente landing pages e experimentos de interface.

O projeto também serve como espaço para praticar JavaScript, organização de código, responsividade e criação dinâmica de conteúdo.

## 🎯 Objetivo

Criar uma galeria simples e visualmente agradável para apresentar projetos desenvolvidos durante minha jornada no desenvolvimento web.

Os projetos são cadastrados em um arquivo JavaScript e os cards são criados dinamicamente através do DOM.

## ✨ Funcionalidades

- 🌸 Galeria de projetos
- 🖼️ Cards com preview dos projetos
- 🔗 Links para os projetos publicados
- 🌙 Tema escuro
- ☀️ Tema claro
- 💾 Tema salvo com `localStorage`
- 🎨 Variáveis CSS para os temas
- ✨ Animações e efeitos de hover
- 📱 Layout responsivo
- 🧩 Renderização dinâmica dos projetos
- 🔮 Card "Coming Soon" inserido automaticamente no final


## 🏷️ Tecnologias

- HTML5
- CSS3
- JavaScript
- ES Modules
- Flexbox
- CSS Variables
- Media Queries
- DOM
- LocalStorage
